# ÉLAN BEAUTY STUDIO — Luxury Salon Website Demo

> “Where Beauty Meets Elegance.”

A bespoke, high-end frontend website demo built for **ÉLAN BEAUTY STUDIO**. Designed to showcase editorial luxury beauty brand standards to potential salon, spa, and aesthetics clients.

---

## ✨ Features & Architecture

- **Visual Design System**:
  - Warm Ivory (`#F8F4EF`)
  - Champagne Gold (`#C5A572`)
  - Soft Beige (`#E9DDD1`)
  - Deep Espresso (`#28201D`)
  - Muted Rose (`#C99A98`)
  - Typography: *Cormorant Garamond* (Editorial serif) & *Plus Jakarta Sans* (Modern sans-serif).
- **Refined Sticky Navigation**:
  - Wordmark logo with animated mobile navigation drawer.
  - Smooth scrolling to all sections with dynamic backdrop blur.
  - Top announcement banner featuring atelier highlights.
- **Hero Section**:
  - Split editorial layout with high-resolution photography.
  - Primary CTAs: “Explore Our Services” & “Book Your Visit”.
  - Luxury badges: 100% Bespoke Consultations, Private VIP Suites, Cruelty-Free Botanical Care.
- **Brand Introduction ("Beauty, Thoughtfully Redefined")**:
  - Two-column editorial storytelling layout with framed architectural imagery.
  - Three brand principles: *Personalized Care*, *Expert Artistry*, and *Exceptional Experience*.
- **Interactive Services Section ("Your Ritual of Beauty")**:
  - 6 signature rituals with category filter tabs (Hair, Skin, Bridal, Nails, Spa).
  - Price guidance badges (“Consultation available” / “Enquire for pricing”).
  - **Service Discovery Modal**: Detailed step-by-step ritual explanation, duration, inclusions, and a 1-click booking preselection.
- **Signature Experience Section**:
  - Visually striking dark espresso (`#28201D`) feature section with champagne gold accents.
  - Four sensory pillars: Private Acoustic Suites, French Champagne & Artisan Tea, Clean Botanical Formulas, Diagnostic Consultation.
- **Transformation Lookbook Gallery**:
  - Asymmetric editorial masonry grid with filter pills.
  - Full-screen **Image Lightbox** with next/prev controls, keyboard arrow navigation, and close support.
- **Meet the Experts**:
  - Fictional master artisan profiles with photography, bios, and specialty tags.
  - Clear client demo notice for ease of client replacement.
- **Illustrative Testimonials ("Loved for the Details")**:
  - 3 luxury review cards with star ratings and client reflections.
  - Clearly marked demo content disclosure.
- **About the Salon ("More Than a Beauty Appointment")**:
  - Atelier story, values checklist, and interior architecture visuals.
- **Appointment Request Section**:
  - Complete reservation form with real-time frontend validation for Name, Phone, Email, Service, Specialist, Date, and Time.
  - Demo confirmation dialog indicating no actual charge/booking was made.
  - Concierge contact card with replaceable demo details and opening hours.
- **Contact & Location**:
  - Replaceable studio address, phone, email, and social links.
  - Interactive architectural map placeholder with direction links.
  - Guest FAQ accordion.
- **Refined Footer**:
  - Atelier links, service directory, and copyright notice.
  - **Configurable ASAI LABS Pitch Credit**: Built-in toggle switch to easily show or hide the “Website concept by ASAI LABS” credit during white-label client presentations.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### Running Locally

```bash
# Install dependencies (if not already installed)
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` to view the website.

### Production Build

```bash
# Build for production
npm run build

# Preview production build
npm run preview
```
